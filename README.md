# DOTA 3 — мини-MOBА в 3D 🎮

▶ **Играть онлайн: <https://qyto14.github.io/dota3/>**

Пародийная мини-МОБА в браузере на **three.js**: ты выбираешь героя на стартовом экране и дерёшься против
ИИ-героя **Моркуса** на одной линии. Снеси две башни врага и разрушь **Трон сумрака** — победа!

> Фанатская пародия, не связанная с Valve. Весь контент игры (модели, текстуры, имена героев) —
> оригинальный, сгенерирован кодом. Звук — синтез браузера.

## Как запустить
Просто открой **`index.html`** двойным кликом (Chrome/Edge/Firefox) — или играй онлайн по ссылке выше.
Интернет не нужен — `three.min.js` лежит рядом.

## Герои (выбор на старте)
| Герой | Архетип | Набор |
|---|---|---|
| **Игнара — Повелительница пламени** | маг · урон | Огненный шар · Рывок · Вихрь огня · Метеор |
| **Криста — Ледяная дева** | маг · контроль | Осколок льда (авто-замедление) · Миг (телепорт к точке) · Ледяная волна · Метель (6 ледяных осколков) |
| **Бастион — Страж рассвета** | боец · живучесть | Ударная волна · Натиск (длинный рывок) · Молот и станина · Баррикада (щит поглощает 45% XП) |

- Герои различаются моделями (капюшон и посох у магов, стальной доспех и щит у Бастиона), статами
  (XП/мана/скорость/дальность атаки) и кулдаунами.
- Бот Моркус воплощается в **случайном архетипе** и играет его китом.

## Управление
| Клавиша | Действие |
|---|---|
| **WASD / стрелки** | Бег героя (прямое управление) |
| **ЛКМ / ПКМ** | Идти к точке; клик по врагу — атаковать |
| **Q / 1** | Огненный шар |
| **Space / 2** | Рывок |
| **E / 3** | Ледяная волна |
| **R / 4** | Метеор (с 4 уровня) |
| **X** | Стоп (отмена приказа) |
| **T** | Свиток телепорта к трону |
| **B** | Магазин |
| **P** | Пауза |
| **M** | Звук вкл/выкл |
| **Курсор у края экрана** | Панорама камеры (как в доте) |
| **СКМ (зажать)** | Тащить карту |
| **Колесо мыши** | Зум камеры |
| **Клик по миникарте** | Камера прыгает в точку |
| **F1** | Камера к герою |
| **F** | Закрепить/открепить камеру |

## Камера
- Камера **свободная**, не привязана к персонажу — как в доте.
- Подводится курсором к краю экрана, тащится СКМ, зумится колесом (18–62).
- F1 мгновенно центрирует вид на герое, F включает мягкое «прилипание».
- Клик по миникарте переносит камеру в соответствующую точку карты.

## Механики
- 💀 Крипы каждые 30 секунд, опыт и золото за добивания (LH); волны усиливаются со временем,
  **каждая 6-я** приносит **супер-крипа**
- 🗼 Две башни с каждой стороны; пока стоит башня — трон под щитом
- 💍 Магазин: меч (+урон), панцирь (+броня), сапоги (+скорость), травник (+реген), эликсир (полное лечение),
  свиток ТП, **Клык Вампира** (+12% вампиризма, стакается), **Кольцо Стихий** (+80 маны и +3/с),
  **Фолиант Знаний** (+260 опыта)
- 🐗 **Нейтральные кемпы** в джунглях (гоблины-мародёры и каменные гарпии) — золото/опыт, респаун 85 с
- 🐉 **Рошан** в каменном логове за рекой — Эгида Рошана пересобирает героя после смерти
- ✨ Руны на реке (багряная, водяная, ускорение)
- ⭐ 12 уровней, характеристики растут, фонтан лечит и восполняет ману
- 🤖 Бот с ИИ: пушит линию, кастует заклинания, отступает на низком ХП
- 🔊 Звук: анонсер-голос («Первая кровь!», «Башня разрушена!», «Победа!») + процедурная
  эмбиент-музыка (тихие пэды) + синтезированные эффекты — всё оффлайн, без чужих файлов
- ⚔ Боевые баннеры по центру: битва началась, первая кровь, уровень, башня, Рошан, супер-крип

## Графика «ультра»
- Небо: купол с золотым горизонтом, звёзды, солнце/луна, плывущие облака; день/ночь цикл с туманом
- HD-текстуры 512² (зерно, анизотропия 8): трава, земля, **кирпичная кладка на башнях и тронах**
- **Blob-тени** под героями, крипами, нейтралами, башнями и Рошаном — читаемость позиции как в MOBA
- Живая река (скролл воды), блики на воде днём, взвесь в воздухе
- Джунгли: 190 деревьев с двойной кроной и вариацией оттенков, 320 кустов травы, камни, горы
- Атмосфера: каменные борюры линии, знамёна, фонари со светлячками ночью, бразьеры на башнях,
  обелиски у тронов, пещера Рошана с валунами
- **Счётчик ФПС** в правой панели (в реальном окне игры показывает честные кадры/с)
- Эффектные заклинания: glow-снаряды с огненным шлейфом, метеор с кратером и трещинами в земле,
  ледяная метель с инеем, столбы света при миге/вихре, рывок с пылью и следом цвета героя,
  Щит Бастиона — живой золотой купол; каждый каст подсвечивает землю под героем
- Весь художественный контент — **оригинальный** (модели и текстуры сгенерированы кодом);
  ассеты Valve/Dota не используются
